🚀 Publicar no GitHub Pages

  1. Salve todo este código em um arquivo local com o nome index.html.
  2. Acesse o GitHub.com e crie um novo repositório público.
  3. Envie (upload) o arquivo index.html para a raiz do repositório.
  4. Vá em Settings > Pages.
  5. Em Source, selecione a branch main (ou master) e clique em Save.
  6. Em 1 minuto seu site estará online no link fornecido pelo GitHub!
